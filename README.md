# PDF Master Pro — By Mr Nazish Alfanso

एक प्रोफेशनल, एडवांस्ड और मोबाइल-फ्रेंडली इन-ब्राउज़र PDF Editor Web App, जो PDF के मूल लेआउट को बिना बिगाड़े टेक्स्ट को सीधे उसकी पुरानी जगह पर बदलने, नया टेक्स्ट जोड़ने, डिजिटल सिग्नेचर लगाने, इमेज और आकृतियां जोड़ने और PDF को मर्ज/स्प्लिट करने की पूर्ण सुविधा प्रदान करता है।

---

## 🌟 मुख्य विशेषताएं (Key Features)

### 1. Direct Text Editing (मूल लेआउट में वास्तविक टेक्स्ट एडिटिंग)
- **क्लिक करके टेक्स्ट एडिट करें:** PDF में किसी भी मौजूदा टेक्स्ट पर क्लिक या डबल क्लिक करें और सीधे उसी जगह पर बदलाव करें।
- **फॉन्ट और लेआउट संरक्षण:** मूल फॉन्ट परिवार (Helvetica/Arial, Times Roman, Courier, आदि), फॉन्ट साइज, टेक्स्ट कलर, बोल्ड और इटैलिक को सुरक्षित रखता है।
- **पृष्ठभूमि रंग मिलान (Background Masking Engine):** टेक्स्ट बदलने पर केवल साधारण सफेद डिब्बा नहीं रखा जाता, बल्कि उस स्थान के मूल बैकग्राउंड रंग का सटीक नमूना लेकर टेक्स्ट को बिना किसी धब्बे के बदला जाता है।
- **हिंदी और यूनिकोड सपोर्ट:** हिंदी (Devanagari) और अन्य यूनिकोड लिपियों में टेक्स्ट लिखने और जोड़ने की सुविधा।
- **फ्लोटिंग फॉर्मेटिंग टूलबार:** टेक्स्ट चुनते ही फॉन्ट साइज, फॉन्ट फैमिली, बोल्ड, इटैलिक, टेक्स्ट रंग, अलाइनमेंट और डिलीट के टूल्स तुरंत उपलब्ध होते हैं।

### 2. PDF Upload और Viewer
- **Drag & Drop और File Picker:** कंप्यूटर या मोबाइल से आसानी से PDF अपलोड करें।
- **मल्टी-पेज सपोर्ट और ज़ूम:** Zoom In, Zoom Out, Fit to Page चौड़ाई के अनुसार।
- **पेज थंबनेल्स पैनल:** बाईं ओर प्रत्येक पेज का रीयल-टाइम थंबनेल, क्विक रोटेट और डिलीट बटन के साथ।
- **डेमो सैंपल PDF:** बिना किसी फाइल के भी एक क्लिक में "Try Demo Sample PDF" से पूरे फीचर्स टेस्ट करें।

### 3. Advanced Editing Tools
- **डिजिटल सिग्नेचर (Digital Signature Stamp):**
  - उंगली या माउस से सिग्नेचर बनाएं (Draw Mode with Ink Color)।
  - सुंदर कर्सिव फॉन्ट में नाम लिखकर सिग्नेचर बनाएं (Type Mode)।
  - सिग्नेचर की इमेज/पीएनजी अपलोड करें।
  - सिग्नेचर को रिसाइज और किसी भी पेज पर ड्रैग करके लगाएं।
- **Add Image & Logos:** कोई भी इमेज/लोगो अपलोड करके पेज पर मनचाहे स्थान पर लगाएं और कोनों से रिसाइज करें।
- **फ्रीहैंड ड्रॉइंग (Pen Tool):** मनचाहे रंग और मोटाई के साथ नोट्स और रेखाएं बनाएं।
- **हाईलाइट, अंडरलाइन और स्ट्राइकथ्रू:** महत्वपूर्ण बिंदुओं को मार्क करें।
- **आकृतियां (Shapes):** आयत (Rectangle), वृत्त (Circle), और तीर/रेखा (Arrow & Line)।

### 4. Page Management (पेज प्रबंधन)
- **Rotate Pages:** किसी भी पेज को 90° क्लॉकवाइज़ या एंटी-क्लॉकवाइज़ घुमाएं।
- **Delete Pages:** अनचाहे पेजों को एक क्लिक में हटाएं।
- **Extract Pages:** किसी भी पेज को अलग PDF बनाकर डाउनलोड करें।
- **Merge PDFs:** कई अलग-अलग PDF फाइलों को आपस में जोड़ें।
- **Split PDF:** पेजों की रेंज (जैसे `1-2, 4`) निर्दिष्ट करके PDF को विभाजित करें।

### 5. Smart Tools & Security
- **OCR Scanner (Scanned PDF Support):** स्कैन की गई या इमेज वाली PDF फाइलों से टेक्स्ट पहचानकर उन्हें एडिटेबल लेयर में बदलें।
- **Compare Mode:** ओरिजिनल PDF और एडिट की गई PDF को साथ-साथ (Side-by-Side) देखकर बदलावों की तुलना करें।
- **Search & Replace (Ctrl+F):** पूरे डॉक्यूमेंट में शब्दों को ढूंढें, एक-एक करके या एक साथ सभी (Replace All) बदलें।
- **Undo / Redo (Ctrl+Z / Ctrl+Y):** हर बदलाव को पूर्ववत या पुनः लागू करें।
- **100% क्लाइंट-साइड सुरक्षा (Zero Server Upload):** आपकी फाइल आपके ब्राउज़र में ही प्रोसेस होती है; किसी भी बाहरी सर्वर पर अपलोड नहीं होती।
- **Dark Mode & Light Mode:** आंखों के आराम के लिए आधुनिक डार्क और लाइट थीम।
- **मोबाइल फ्रेंडली बॉटम बार:** स्मार्टफोन पर भी आसान नेविगेशन और एडिटिंग।

## 🚀 Vercel पर डिप्लॉय करने का तरीका (Deploy to Vercel)

यह प्रोजेक्ट 100% स्टैटिक और सर्वरलेस है, जिसे Vercel पर 1 मिनट में लाइव किया जा सकता है:

### तरीका 1: Vercel Dashboard से (सबसे आसान)
1. प्रदान की गई `PDF-Master-Pro.zip` फाइल को अपने कंप्यूटर पर Unzip करें।
2. [Vercel](https://vercel.com) पर लॉगिन करें।
3. **"Add New Project"** पर क्लिक करें।
4. इस फोल्डर को अपने GitHub रिपॉजिटरी में पुश करके Vercel में Import करें, या Vercel CLI का इस्तेमाल करें।
5. Project Settings में **Framework Preset** को `Other` रखें (रूट डायरेक्टरी `./`).
6. **"Deploy"** पर क्लिक करें। आपकी वेबसाइट तुरंत लाइव हो जाएगी!

### तरीका 2: Vercel CLI द्वारा
अपने टर्मिनल में इस प्रोजेक्ट फोल्डर में जाएं और चलाएं:
```bash
npm install -g vercel
vercel
```
और प्रोडक्शन डिप्लॉय के लिए:
```bash
vercel --prod
```
